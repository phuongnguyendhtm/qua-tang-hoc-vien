## 🛠️ HƯỚNG DẪN SỬ DỤNG

### Cách chạy (Dán vào Antigravity Chat)

**Chạy tự động 6 skill nền tảng liên tiếp:**

> Hãy đọc thư mục `freeup-plugins/` và chạy Foundation Builder cho tôi. Bắt đầu từ Avatar Builder, rồi lần lượt Brand Voice, Hero Mechanism, Money Model, Offer Architect, HVCO Creator.

**Hoặc chạy từng skill riêng lẻ:**

> Hãy đọc file `freeup-plugins/freeup-avatar-builder/SKILL.md` và chạy skill này cho tôi.

Thay `freeup-avatar-builder` bằng tên skill bạn muốn.
